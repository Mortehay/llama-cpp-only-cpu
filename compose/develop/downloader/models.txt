# Models fetched by the downloader container into $MODELS_DIR.
#
# IMPORTANT: this file is ONLY for the llama.cpp `llm-server` service (the chat
# models in Open WebUI). The sprite generator does NOT read it — diffusers
# pulls its checkpoints via from_pretrained() on first use, into the same
# directory as an HF cache (models--stabilityai--sdxl-turbo/...). Adding a
# diffusers model here does nothing useful.
#
# Format: one entry per line, `<repo_id> <file_name>`.
#
# A missing entry 404s and aborts the whole run (set -e), so every repo below
# has been verified to exist, with the size measured from its HEAD response.
#
# SIZING FOR A 12GB CARD. These are 8-9GB fully offloaded to VRAM, plus ~0.5-1GB
# of KV cache, so a loaded chat model occupies most of the card. That is
# deliberate — see docker-compose.cuda.yml — and it works alongside sprite
# generation only because `--sleep-idle-seconds` makes the server release the
# GPU when nobody is chatting. Two of these loaded at once will not fit, which
# is why the server runs with `--models-max 1`.
