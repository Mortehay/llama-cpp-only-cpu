# By-eye verdicts on repaired entity references.
#
# Read by scripts/recover-grid-refs.py and applied after every automatic check.
# These exist because `measure` sees a single centred opaque blob and cannot
# ask how much of that blob is the entity, nor whether a detached blob is
# litter or the art. Both questions decide whether a file is usable, and
# neither is answerable by a threshold.
#
# Format:   filename<spaces>verdict<spaces>reason
#
# Verdicts:
#   reject        unusable; the reason says what is wrong with it
#   drop-strays   the detached blobs are litter - apply _isolate_largest_sprite
#   keep-strays   the detached blobs ARE the art - the stray finding is a false
#                 positive and is suppressed, the file is used as it stands
#
# drop-strays is not the default and must never become one. At generation time
# _isolate_largest_sprite is unconditionally right, because a generated
# duplicate is always a defect. On a REFERENCE a detached part may be the
# subject, and the difference is only visible by looking: rendered with the
# doomed pixels in red by scripts/show-strays.py.
#
# Checked at 1:1 and upscaled on 2026-08-27.
